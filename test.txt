Сортування бульбашкою — Bubble Sort

Масив: [5, 3, 8, 1, 2]

Алгоритм:
1. Порівнюємо два сусідні елементи.
2. Якщо лівий елемент більший за правий — міняємо їх місцями.
3. Повторюємо проходи, поки масив не буде відсортований.

Псевдокод:

для i від 0 до n - 1:
    для j від 0 до n - i - 2:
        якщо array[j] > array[j + 1]:
            поміняти array[j] та array[j + 1]

Результат: [1, 2, 3, 5, 8]
